# SEC Filing Fee Calculator

Free no-tracking SEC filing fee calculator using the FY2026 filing fee rate for 10/1/2025 to 9/30/2026:

- `$138.10 per $1,000,000`
- `0.00013810` times the aggregate amount

The tool runs entirely in the browser. It has no signup, cookies, analytics, beacons, external scripts, uploads, or browser storage.

Useful checks now included on the page:

- Common amount examples from $1,000,000 through $1,000,000,000.
- A Section 31 clarification so visitors do not confuse SEC filing fees with broker-dealer transaction fees.
- FAQ structured data for the rate, EDGAR/FEPT validation boundary, and Section 31 boundary.
